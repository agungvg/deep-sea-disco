**Deep Sea Disco** is an underwater disco base game for Roblox: catch absurd dancing sea critters in the Open Water, carry them back to your own disco base, and set them dancing on pedestals — each one earns Bubbles every second. Sell critters (E), buy upgrades, and complete the 42-critter Index for a +42% Bubbles bonus. Live events keep the floor moving: **Disco Fever** (x2 Bubbles for 45s), the **Net Nabber** thief crab who steals a critter and flees for the trench portal, and the **Shark Sweep** hazard that knocks your catch loose. Lock your base with **Go Dark** before the crab comes.

- 42 original critters across 6 tiers (Common → Abyssal), each a part-built chibi dancer with its own face, prop, and $/s label.
- Server-authoritative economy, spawns, events, and DataStore saves; the client owns input, camera, HUD, and juice (trauma shake, floating income labels, event banners, pickup bursts, count-up numbers).
- Deep teal water, coral orange, warm sand, and lime — no neon pink.

## Run it

```sh
rojo build default.project.json --output game.rbxl
```

Open `game.rbxl` in Roblox Studio, press Play, and walk into the Open Water. `main.ts` hands the entry in (`mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`).
